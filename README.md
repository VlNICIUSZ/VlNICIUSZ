### 💻 Projetos em Destaque

#### 🧭 Route

Aplicação de **navegação indoor acessível para pessoas com deficiência visual**, desenvolvida como projeto acadêmico de Engenharia de Software.

O projeto busca utilizar tecnologia para auxiliar na orientação dentro de ambientes fechados, com foco em **acessibilidade, comandos por voz, localização e experiência do usuário**.

**Tecnologias e conceitos envolvidos:**

- C#
- .NET MAUI
- XAML
- Git e GitHub
- UX/UI
- Acessibilidade
- Navegação indoor
- Bluetooth / Beacons
